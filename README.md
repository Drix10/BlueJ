# BlueJ Java Programs: Beginner Java Practice

Java programs I wrote while learning **Java in the BlueJ IDE**: short, self-contained practice programs that start with Scanner input and simple arithmetic. Useful for school students and beginners practising core Java.

## Contents

- `P11.java` to `P21.java` and more: numbered practice programs
- `A.java`, `DRIX10.java`: extra exercises

## Run a program

Open the folder as a project in [BlueJ](https://www.bluej.org/), or compile from the terminal:

```bash
javac P11.java
java P11
```
